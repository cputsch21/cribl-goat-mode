# 🐐 GOAT Mode — Cribl Interview Prep

A personal course app: 10 modules, 10 quizzes, 2 boss-level interview simulations,
46 flashcards, and per-interviewer cram sheets — built from real interview
transcripts plus cribl.io, with every fact tagged to its source.

Pass everything at 90%+ and walk into the Kat and Cam calls 3x more prepared
than you need to be.

- **Stack:** Next.js (App Router) · Tailwind CSS v3 · AI SDK via Vercel AI Gateway
- **Progress:** saved on-device, no sign-in
- **PWA:** installable, lessons and quizzes work offline
- **Practice Room:** AI role-plays Kat (channel), Cam (SE leader), or a coach
